# 出图前自检清单

每轮提交 codex 评审前，必须逐项确认：

## 结构正确性
- [ ] 是否已经确认顶层模型范式（decoder-only / encoder-decoder / VLM / hybrid）
- [ ] 是否已经确认主干 forward 路径
- [ ] 是否已经确认 attention 类型
- [ ] 是否已经确认 norm 类型与顺序
- [ ] 是否已经确认 MLP / FFN / gate / activation
- [ ] 是否已经确认 residual 路径
- [ ] 是否已经确认 projector / connector / merger 的位置与作用
- [ ] 是否已经确认输出头类型

## 图面完整性
- [ ] 输入是否在最上方
- [ ] 输出是否在最下方
- [ ] 主流程是否清楚
- [ ] 支路关系是否清楚
- [ ] 重复模块是否只展开一次并标注 ×N
- [ ] 模块名称是否准确
- [ ] 是否体现了关键实现细节

## 可读性
- [ ] 箭头是否没有穿过模块主体
- [ ] 布局是否规整
- [ ] 模块层级是否清晰
- [ ] 文本标签是否不过长
- [ ] 图中是否不存在明显歧义

## 多模态专项
- [ ] 图像分支是否画清楚
- [ ] 文本分支是否画清楚
- [ ] 融合位置是否画清楚
- [ ] projector / adapter 是否画清楚
- [ ] 输出任务头是否与实现一致

## 提交评审前
- [ ] 是否已经形成源码依据摘要
- [ ] 是否已经形成 config 依据摘要
- [ ] 是否已经准备好给 codex 的评审说明
