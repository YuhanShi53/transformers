RoPE (Rotary Position Embedding) 由苏剑林在 2021 年的 RoFormer 论文中提出。它通过旋转变换将位置信息注入到 Query 和 Key 向量中，使得两个 token 的注意力分数仅取决于它们的相对距离，而非绝对位置。

如今，几乎所有主流大语言模型（LLaMA、GPT-NeoX、Qwen、DeepSeek、Mistral 等）都使用 RoPE 作为位置编码方案。

为什么 Transformer 需要位置编码？

Transformer 的自注意力机制本质上是一个集合操作（set operation）——它对输入 token 做加权求和，但完全不关心 token 的顺序。如果不加位置编码，"猫追狗" 和 "狗追猫" 在 Transformer 眼中是完全一样的。

没有位置编码

Attention(Q, K, V) 的结果与输入顺序无关。对于排列 π：

Attention(π(X)) = π(Attention(X))

"I love you" = "you love I" = "love I you"

有位置编码

位置编码打破了排列等变性，使模型能区分不同顺序：

f(x, pos) ≠ f(x, pos')

"I love you" ≠ "you love I"

2. 直觉理解：为什么是旋转？

核心直觉：旋转角度 = 位置

想象一个时钟：时针指向不同的角度代表不同的时间。RoPE 的思路完全类似——把向量旋转不同的角度来表示不同的位置。

  • 位置 0 的 token：不旋转（旋转 0°）
  • 位置 1 的 token：旋转 θ°
  • 位置 2 的 token：旋转 2θ°
  • 位置 m 的 token：旋转 mθ°

为什么旋转能编码"相对"位置？

RoPE 最精妙的地方在于：当计算 Query 和 Key 的内积时，旋转角度的差值自然体现了两个 token 的相对距离。

⟨ R(mθ) · q,   R(nθ) · k ⟩  =  ⟨ R((m − n)θ) · q,   k ⟩
内积只依赖相对距离 (m − n)，而非绝对位置 m 或 n
直觉类比：音乐中的移调

两个音符之间的"音程"（相对关系）不会因为你把整首曲子移调而改变。C-E 是大三度，D-F# 也是大三度。RoPE 中的旋转就像移调——绝对"音高"（位置）变了，但两个 token 之间的"音程"（相对距离）保持不变。

3. 数学原理

3.1 从 2D 旋转矩阵开始

在二维平面上旋转一个向量 (x₁, x₂)，只需要乘以一个旋转矩阵：

R(θ) = ( cosθ   −sinθ
sinθ     cosθ )
2D 旋转矩阵：将向量逆时针旋转 θ 角

关键性质：

  • 保范性：旋转不改变向量长度，||R(θ)x|| = ||x||
  • 可加性：R(α) · R(β) = R(α + β)
  • 正交性：R(θ)ᵀ = R(−θ) = R(θ)⁻¹

对于位置 m 的 token，RoPE 将其 Query/Key 向量旋转 mθ 角度：

q'm = R(mθ) · qm = ( cos(mθ)   −sin(mθ)
sin(mθ)     cos(mθ) ) ( q₁
q₂ )

3.2 推广到高维：分组旋转

实际的 Query/Key 向量是 d 维的（如 128 维）。RoPE 将 d 维向量两两分组，每组用不同的频率旋转：

完整的 d 维 RoPE 旋转矩阵是一个分块对角矩阵：

Rd(m) = diag( R(mθ₁), R(mθ₂), ..., R(mθd/2) )
d/2 个独立的 2D 旋转，每个频率不同

其中频率按照几何级数递减：

θi = base−2(i−1)/d,    i = 1, 2, ..., d/2,    base = 10000
默认 base = 10000，产生从高频到低频的一系列旋转频率

3.3 复数形式：更优雅的表达

将每对相邻元素 (q₂ᵢ₋₁, q₂ᵢ) 看作一个复数 q₂ᵢ₋₁ + q₂ᵢ · i，则旋转就变成了复数乘法：

q'i = qi · eimθi = (q₂ᵢ₋₁ + q₂ᵢ · i) · (cos(mθi) + sin(mθi) · i)
复数乘以单位圆上的点 = 旋转！这就是 RoPE 最简洁的形式
为什么复数形式在代码中更常用？

复数乘法只需要 2 次乘法 + 1 次加减，而矩阵乘法需要 4 次乘法 + 2 次加减。在实际实现中（如 LLaMA），通常将向量 reshape 为复数张量后直接做逐元素复数乘法，避免构造和存储巨大的旋转矩阵。

展开后的实数计算公式（代码中最终执行的操作）：

q'₂ᵢ₋₁ = q₂ᵢ₋₁ · cos(mθi) − q₂ᵢ · sin(mθi)
q'₂ᵢ    = q₂ᵢ₋₁ · sin(mθi) + q₂ᵢ · cos(mθi)

3.4 Q·K 内积：相对位置的数学证明

现在来证明为什么 RoPE 能编码相对位置。设位置 m 的 Query 和位置 n 的 Key：

⟨ q'm, k'n ⟩
= ⟨ R(mθ) q, R(nθ) k ⟩
= qᵀ R(mθ)ᵀ R(nθ) k
= qᵀ R(−mθ) R(nθ) k     (正交矩阵性质)
= qᵀ R((n − m)θ) k     (旋转可加性)
= g(q, k, n − m)     只依赖相对距离！
关键结论

经过 RoPE 旋转后，Q 和 K 的内积（即注意力分数）只是相对距离 (n−m) 的函数。无论 token 在序列中的绝对位置如何，只要两个 token 之间的距离相同，它们的注意力分数就相同。

4. 频率设计与长度外推

4.1 频率基底 θ 的设计

RoPE 的频率公式 θᵢ = base⁻²⁽ⁱ⁻¹⁾/ᵈ 的设计灵感来自原始 Transformer 的正弦位置编码，但有本质区别：

正弦位置编码 (Sinusoidal)

将 sin/cos 值加到 token 嵌入上

加法破坏了向量的内积结构

位置信息和语义信息混合

RoPE

用 sin/cos 构造旋转矩阵，乘以 Q/K

旋转保持内积的"相对位置"特性

位置信息融入注意力计算本身

不同维度对 (pair) 的频率形成一个从高频到低频的频谱：

频率的直觉：多尺度位置编码

类比十进制数字：个位数变化最快（高频），十位次之，百位更慢（低频）。RoPE 中前几个维度对像"秒针"（快速旋转，分辨近距离），后面的维度对像"时针"（缓慢旋转，分辨远距离）。这种多尺度编码使得 RoPE 既能区分相邻 token，也能感知远距离依赖。

4.2 长度外推：超越训练长度

RoPE 的一大优势是支持长度外推——模型能泛化到比训练时更长的序列。方法是调整 base 参数：

方法策略base 值效果
原始 RoPE—10,000训练长度内表现好
Code LLaMA增大 base1,000,00016K → 100K
DeepSeek-V4增大 base10,000,000256K
YaRN分段缩放动态高倍外推
NTK-aware动态 base按长度调整无需微调外推

增大 base 的直觉：base 越大，所有频率越低，旋转越慢。这意味着在更长的序列上，旋转角度的变化更加平缓，避免了高频维度"绕圈太多"导致的周期性混淆。

base ↑  ⇒  θi ↓  ⇒  每个位置的旋转角度更小  ⇒  可表示更长序列

5. RoPE 的关键优势

相对位置编码

注意力分数仅依赖 token 间相对距离，天然适合语言建模中的平移不变性需求

保范性

旋转不改变向量长度，不会引入额外的 scale 偏差，训练更稳定

远距离衰减

相对距离越大，高频分量旋转越多，内积自然衰减，模拟局部性偏好

可扩展性

通过调整 base 或分段缩放，灵活外推到任意长度，无需修改模型结构

远距离衰减的直觉解释

当两个 token 距离较远时，每个维度对的旋转角度差 (m-n)θᵢ 都很大。高频维度的 cos 值会剧烈振荡、正负抵消，使得这些维度对内积的贡献趋近于零。只有最低频的几个维度还能保持一致的方向。

这产生了一种天然的局部性偏好：近距离 token 对的内积更大（更多维度"对齐"），远距离 token 对的内积更小。这与语言中"近处的词通常更相关"的先验一致。

6. 代码实现

以下是 RoPE 的 PyTorch 实现，基于 LLaMA 的风格，逐步分解。

6.1 预计算频率表 (freqs_cis)

import torch

def precompute_freqs_cis(dim: int, seq_len: int, base: float = 10000.0):
    # 计算每个维度对的频率: theta_i = 1 / base^(2i/d)
    freqs = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
        # [d/2] — 从高频到低频的频率序列

    # 位置序列: [0, 1, 2, ..., seq_len-1]
    t = torch.arange(seq_len).float()
        # [seq_len]

    # 外积: 每个位置 × 每个频率 = 旋转角度矩阵
    angles = torch.outer(t, freqs)
        # [seq_len, d/2] — angles[m][i] = m * theta_i

    # 转为复数形式: e^(i*angle) = cos(angle) + i*sin(angle)
    freqs_cis = torch.polar(torch.ones_like(angles), angles)
        # [seq_len, d/2] — 复数张量，每个元素在单位圆上

    return freqs_cis
步骤操作输出 Shape说明
1arange(0, d, 2) / d[d/2]归一化维度索引
2base ** (-indices)[d/2]频率 θᵢ = base⁻²ⁱ/ᵈ
3outer(positions, freqs)[seq_len, d/2]旋转角度矩阵
4polar(1, angles)[seq_len, d/2]复数旋转因子 eimθᵢ

6.2 应用旋转到 Q/K

def apply_rotary_emb(
    q: torch.Tensor,     # [batch, seq_len, n_heads, head_dim]
    k: torch.Tensor,     # [batch, seq_len, n_kv_heads, head_dim]
    freqs_cis: torch.Tensor  # [seq_len, head_dim/2]
):
    # 将实数张量视为复数: 相邻两个元素组成一个复数
    q_complex = torch.view_as_complex(q.float().reshape(*q.shape[:-1], -1, 2))
        # [batch, seq_len, n_heads, head_dim/2] complex64
    k_complex = torch.view_as_complex(k.float().reshape(*k.shape[:-1], -1, 2))
        # [batch, seq_len, n_kv_heads, head_dim/2] complex64

    # 广播 freqs_cis 到 [1, seq_len, 1, head_dim/2]
    freqs = freqs_cis.unsqueeze(0).unsqueeze(2)

    # 核心操作：复数逐元素乘法 = 旋转！
    q_rotated = q_complex * freqs    # [b, s, nh, hd/2] 复数乘法
    k_rotated = k_complex * freqs    # [b, s, nkv, hd/2]

    # 转回实数张量
    q_out = torch.view_as_real(q_rotated).flatten(-2)
        # [batch, seq_len, n_heads, head_dim]
    k_out = torch.view_as_real(k_rotated).flatten(-2)
        # [batch, seq_len, n_kv_heads, head_dim]

    return q_out.type_as(q), k_out.type_as(k)
核心操作只有一行

q_rotated = q_complex * freqs — 复数乘法自动完成了旋转！

这等价于：对每对 (q₂ᵢ₋₁, q₂ᵢ)，执行 2×2 旋转矩阵乘法。但复数乘法更快、更简洁。

6.3 不使用复数的实数版本 (展开形式)

有些框架不支持复数运算，可以用纯实数实现：

def apply_rotary_emb_real(x, freqs_cos, freqs_sin):
    # x: [batch, seq_len, n_heads, head_dim]
    # 将 head_dim 拆分为两半
    x1 = x[..., : x.shape[-1] // 2]   # 偶数维度
    x2 = x[..., x.shape[-1] // 2 :]   # 奇数维度

    # 旋转公式: [cos, -sin; sin, cos] * [x1, x2]
    out1 = x1 * freqs_cos - x2 * freqs_sin
    out2 = x1 * freqs_sin + x2 * freqs_cos

    return torch.cat([out1, out2], dim=-1)

注意：这里将向量的前半和后半分别当作 "实部" 和 "虚部"，与将相邻元素配对的方式等价（只要保持一致即可）。

10. RoPE 变体与扩展

变体核心改动目标代表模型
NTK-aware RoPE base 按序列长度比例缩放 免微调外推 社区实验
YaRN 按频率分三段，分别：不动 / 线性插值 / NTK 高倍外推 + 保持近距离精度 Mistral, DeepSeek

YaRN 的分段策略细节

YaRN 将频率维度分为三段：

  • 低频段（波长 > 原始训练长度）：直接缩放（NTK 方式）
  • 中频段：NTK 和线性插值的混合
  • 高频段（波长 << 训练长度）：保持不变

这样做的理由是：高频维度编码的是近距离关系，训练时已经见过足够多的模式，不需要调整；而低频维度编码远距离关系，是外推时需要重点调整的部分。

11. 总结

一句话总结

RoPE 把位置编码从 "给 token 贴标签"（绝对编码）变成了 "让 token 转起来"（旋转编码）。每个 token 被旋转的角度取决于它的位置，而两个 token 注意力分数只取决于它们旋转角度的差——也就是相对距离。这个简单而优雅的想法，让模型既能精确感知 token 顺序，又能灵活适应不同长度的序列。
